# Gestor de Productos en Go

Aplicación de consola desarrollada en Go que permite listar productos, agregar nuevos productos y salir del programa mediante un menú interactivo.

## Características

- Listar los productos registrados.
- Agregar nuevos productos con nombre y precio.
- Mostrar los precios con dos decimales.
- Validar opciones inválidas del menú.
- Ejecutarse directamente desde la terminal.

## Requisitos

- Go 1.18 o superior.

Puedes comprobar que Go está instalado con:

```bash
go version
